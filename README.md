## 数据集摘要![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/6a335494b7ff4fcdafea810a20413520.png)

本数据集由DJI mini3无人机采集，共558张路面图像，分辨率1920×1080，采集高度20~60m，拍摄角度覆盖45°至90°。标签包含JSON、TXT两种格式，针对路面坑洞单类别做分割标注，适配道路缺陷分割任务，场景贴近农村道路，适合低空航拍道路病害识别模型训练。

## 应用价值
1. **航拍视角贴合落地场景**：无人机低空多角度拍摄，适配农村道路无人巡检方案；
2. **双标签格式**：JSON、TXT标签，可灵活适配分割、检测模型；
3. **场景聚焦农村路面**，数据贴合乡村道路养护实际需求，泛化性强；
4. 单类别坑洞标注，适合快速搭建道路病害分割基线模型。
